   Formal Problem Statement
   • In a restart-only workflow, interruption discards partial repair progress. Reusing that progress requires checking whether external path changes have invalidated its
   planning context.
   • This project investigates bounded checkpointing, conservative compatibility validation and a heuristic controller that chooses between resumption and a fresh repair
   within the remaining budget.
